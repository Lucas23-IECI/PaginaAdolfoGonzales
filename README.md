# Adolfo Gonzalez - Detección de Fugas

Este repositorio contiene el código fuente de la Landing Page para los servicios profesionales de detección de fugas de agua proporcionados por Adolfo Gonzalez Soto.

## Descripción del Proyecto

Aplicación web enfocada en la conversión y presentación de servicios técnicos de detección de fugas mediante tecnología acústica y gas trazador en el Gran Concepción. El diseño prioriza la claridad, el profesionalismo y el acceso rápido a los canales de contacto directo.

## Stack Tecnológico

- **Framework:** React 19 con Vite
- **Estilos:** Tailwind CSS 3
- **Animaciones:** Framer Motion
- **Iconografía:** Lucide React
- **Enrutamiento:** React Router DOM
- **Lenguaje:** TypeScript

## Estructura del Proyecto

- \`/src/components/\`: Contiene todos los componentes principales (Navbar, Hero, Services, Contact, Footer, etc.).
- \`/src/components/pages/\`: Vistas de páginas completas (Home, Privacy, Terms).
- \`/src/types.ts\`: Interfaces y tipos de TypeScript.
- \`/index.css\`: Archivo principal de estilos y configuración de Tailwind.

## Comandos Disponibles

En el directorio del proyecto, puedes ejecutar:

### \`npm install\`
Instala todas las dependencias necesarias para ejecutar el proyecto.

### \`npm run dev\`
Inicia la aplicación en modo de desarrollo. El navegador recargará la página automáticamente si realizas modificaciones en el código.

### \`npm run build\`
Compila la aplicación para producción en la carpeta \`dist\`. Agrupa React en modo de producción y optimiza los archivos para obtener el mejor rendimiento.

## Despliegue

La aplicación está lista para ser desplegada en plataformas de alojamiento de sitios estáticos modernos como Vercel, Netlify o Cloudflare Pages de manera directa. No requiere configuraciones especiales adicionales.
